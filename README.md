# EduVerse — Образовательная платформа онлайн-обучения

Полнофункциональная веб-платформа онлайн-обучения **EduVerse** с серверной частью на JavaScript (Node.js & Express), встроенной базой данных SQLite и 11 адаптивными страницами, разработанная в точном соответствии с техническим заданием.

Слоган платформы: **«Открываем знания всему миру»**.

---

## 🛠 Стек технологий

- **Клиентская часть (Frontend)**:
  - Семантическая разметка HTML5 (11 страниц с доступностью и комментариями структуры блоков).
  - Стили CSS3 (сброс стилей `reset.css`, дизайн-система `style.css`, Google Fonts: Inter и Plus Jakarta Sans, гибкие сетки Flexbox и CSS Grid, полная адаптивность под мобильные, планшеты и десктоп).
  - Клиентский JavaScript (`js/main.js`): управление сессией, динамическая шапка, модальные окна, уведомления (toasts), оформление заказов и просмотр сертификатов.
- **Серверная часть (Backend)**:
  - Node.js (v20+ / v22)
  - Express.js (`server.js`) — REST API для всех сущностей платформы, обслуживание статики.
  - CORS, JSON Body Parser.
- **База данных**:
  - SQLite (`node:sqlite`, файл `eduverse.db` с автоматической инициализацией и сидированием данных через `db.js`).

## 🚀 Быстрый старт и запуск проекта

### 1. Предварительные требования
- Установленный **Node.js** версии 18, 20 или 22+
- Пакетный менеджер **npm** (или bun/yarn)

### 2. Установка зависимостей
В корневой директории проекта выполните команду:
```bash
npm install
```

### 3. Запуск веб-сервера
Запуск в режиме разработки или продакшн:
```bash
npm run dev
# или
npm start
```
Сервер запустится по адресу: **http://localhost:3000** (или на выделенном порту окружения).

> База данных `eduverse.db` создается и заполняется демонстрационными курсами, уроками, преподавателями, отзывами и статьями автоматически при первом старте сервера.

## 📄 Обзор 11 страниц платформы

1. **Главная страница (`index.html`)**:
   - Название платформы «EduVerse».
   - Слоган *«Открываем знания всему миру»* и описание преимуществ обучения (качественный контент, гибкое расписание, практические навыки).
   - Популярные категории курсов с мгновенным переходом в каталог с предвыбранным фильтром.
   - Блок «Рекомендуемые курсы» с динамической подгрузкой карточек из базы данных.
   - Блок с реальными отзывами студентов (включая отзыв Ильи Лекалина).
   - Интеллектуальная шапка с кнопками входа/регистрации или профиля авторизованного пользователя.

2. **Каталог курсов (`catalog.html`)**:
   - Живой поиск в реальном времени по названию курса, автору или категории.
   - Фильтры: по категориям (чекбоксы), уровню сложности (начальный, средний, продвинутый), стоимости (платные/бесплатные) и минимальному рейтингу (4.0+, 4.5+, 4.8+).
   - Сортировка: по популярности, новизне, цене (возрастание/убывание) и рейтингу.
   - Карточки курсов с ценами со скидками и кнопками записи/покупки в 1 клик.
   - Пагинация для удобной навигации по страницам каталога.

3. **Карточка курса (`course.html?id=:id`)**:
   - Полное название, категория, автор с профилем компетенций, рейтинг и количество отзывов.
   - Стоимость с расчетом скидки и кнопка «Купить курс» / «Записаться бесплатно».
   - Интерактивный плеер с видео-превью курса.
   - Разделы: «О курсе», «Чему вы научитесь» (список навыков), «Для кого предназначен» и теги технологий.
   - Структурированная программа обучения по модулям и урокам с указанием хронометража.
   - Блок отзывов студентов с формой выставления звездной оценки (1–5 звезд) и добавления комментария в БД.

4. **Воспроизведение учебного контента (`lesson.html?id=:id`)**:
   - Учебный кабинет студента: модуль, тема урока и название курса.
   - Два режима воспроизведения:
     - **Видеоурок**: HTML5 видеоплеер с панелью управления.
     - **Интерактивный код (Playground)**: встроенный редактор JavaScript с кнопкой «▶ Запустить код», безопасным изолированным выполнением и выводом в интерактивную консоль.
   - Шкала прогресса курса в процентах и кнопка «Отметить как пройденный» с сохранением прогресса в БД SQLite.
   - Навигация между уроками («Предыдущий урок» / «Следующий урок») и сайдбар со списком всех уроков.
   - Скачивание дополнительных методических материалов к уроку.
   - Блок «Вопросы преподавателю по уроку» с отправкой вопроса и отображением ответов наставника.

5. **Мои курсы (`my-courses.html`)**:
   - Кабинет студента с персональным приветствием.
   - Статусы курсов («В процессе» и «Завершён») с индикаторами прогресса выполнения (0–100%).
   - Карточки купленных курсов с кнопкой продолжения обучения с нужного урока.
   - Модальное окно **официального сертификата EduVerse** (с именем студента, названием курса, печатью и кнопкой сохранения/печати в PDF).
   - Персональные рекомендации курсов на основе истории обучения.

6. **Вход и регистрация (`auth.html`)**:
   - Форма авторизации (email, пароль).
   - Форма регистрации с валидацией, выбором роли (студент или преподаватель) и подтверждением пароля.
   - Форма восстановления пароля по электронной почте.

7. **Личный кабинет преподавателя (`teacher.html`)**:
   - Сводные показатели: количество студентов, курсов, средний рейтинг и общий доход.
   - Управление курсами: добавление нового курса (модальная форма), редактирование и удаление.
   - Добавление новых уроков в программу курса (видео или интерактивная практика, материалы).
   - Раздел ответов на вопросы студентов по урокам с фиксацией в базе данных.
   - Редактирование профиля преподавателя (ФИО, специализация, опыт, биография, аватар).

8. **Административная панель (`admin.html`)**:
   - Общая аналитика платформы: число пользователей, преподавателей, заказов и выручка.
   - Управление пользователями: просмотр списка, мгновенная блокировка/разблокировка, изменение роли (`student`, `teacher`, `admin`).
   - Модерация курсов платформы: просмотр и удаление.
   - Управление категориями: создание новых категорий и удаление существующих.
   - Управление блогом: создание, публикация и удаление статей.

9. **О нас (`about.html`)**:
   - Миссия, видение и ключевые ценности образовательной платформы EduVerse.
   - Хронология и история создания платформы по годам (2023–2026).
   - Команда проекта (руководители, ведущие разработчики, методисты программ).

10. **Преподаватели (`teachers.html`)**:
    - Каталог экспертов платформы, загружаемый из базы данных.
    - Карточки наставников: фото, биография, сфера экспертизы, рейтинг, стаж работы и список авторских программ с переходом на страницу курса.

11. **Блог платформы (`blog.html`)**:
    - Статьи на темы карьеры, образования, технологий и саморазвития.
    - Поиск по статьям в реальном времени и фильтрация по рубрикам.
    - Чтение полной статьи в модальном окне с подсчетом просмотров.
    - Интерактивная система комментариев с сохранением в БД SQLite.

## 🗄 Структура базы данных (`eduverse.db`)

База данных содержит 10 связанных таблиц:
1. `categories` — категории курсов (`id`, `slug`, `name`, `icon`, `description`).
2. `users` — пользователи (`id`, `full_name`, `email`, `password`, `role`, `avatar`, `bio`, `expertise`, `experience`, `is_blocked`, `created_at`).
3. `courses` — курсы (`id`, `category_id`, `teacher_id`, `title`, `slug`, `description`, `what_you_will_learn`, `target_audience`, `skills`, `level`, `price`, `discount_price`, `is_free`, `image`, `preview_video`, `rating`, `reviews_count`, `students_count`).
4. `lessons` — уроки курсов (`id`, `course_id`, `module_title`, `title`, `lesson_order`, `duration`, `video_url`, `code_snippet`, `lesson_type`, `materials_name`, `materials_url`).
5. `orders` — оформленные заказы курсов (`id`, `user_id`, `course_id`, `price_paid`, `status`, `payment_method`, `created_at`).
6. `reviews` — отзывы студентов о курсах (`id`, `course_id`, `user_id`, `rating`, `comment`, `created_at`).
7. `progress` — прогресс прохождения уроков (`id`, `user_id`, `course_id`, `lesson_id`, `completed`, `updated_at`).
8. `questions` — вопросы студентов по урокам и ответы наставников (`id`, `lesson_id`, `course_id`, `student_id`, `question_text`, `answer_text`, `answered_by`, `answered_at`).
9. `blog_posts` — статьи блога (`id`, `title`, `slug`, `category`, `summary`, `content`, `image`, `author_id`, `views`, `created_at`).
10. `blog_comments` — комментарии к статьям блога (`id`, `post_id`, `user_id`, `user_name`, `content`, `created_at`).

## 🔌 Основные API эндпоинты

- **Авторизация**:
  - `POST /api/auth/register` — регистрация нового пользователя (студент или преподаватель).
  - `POST /api/auth/login` — вход по email и паролю.
  - `POST /api/auth/reset-password` — запрос на сброс пароля.
  - `GET /api/auth/me` — получение данных текущей сессии.
- **Курсы и категории**:
  - `GET /api/courses` — поиск, фильтрация, сортировка и пагинация курсов.
  - `GET /api/courses/:id` — детальная информация о курсе, модули, уроки и отзывы.
  - `POST /api/courses/:id/reviews` — добавление отзыва и оценки к курсу.
  - `GET /api/categories` — список категорий с количеством активных курсов.
- **Обучение и прогресс**:
  - `GET /api/lessons/:id` — данные урока, навигация (следующий/предыдущий) и вопросы.
  - `POST /api/lessons/:id/toggle-complete` — переключение статуса прохождения урока.
  - `POST /api/lessons/:id/questions` — отправка вопроса наставнику по уроку.
  - `GET /api/my-courses` — список записанных курсов студента с расчетом прогресса в %.
  - `POST /api/orders/checkout` — запись на курс / оформление заказа.
- **Кабинет преподавателя**:
  - `GET /api/teacher/dashboard` — статистика преподавателя, список курсов и вопросов.
  - `POST /api/teacher/courses` — создание нового курса.
  - `PUT /api/teacher/courses/:id` — редактирование курса.
  - `DELETE /api/teacher/courses/:id` — удаление курса.
  - `POST /api/teacher/courses/:id/lessons` — добавление урока в программу курса.
  - `POST /api/teacher/questions/:id/answer` — отправка ответа студенту на вопрос по уроку.
  - `PUT /api/teacher/profile` — сохранение данных профиля преподавателя.
- **Администрирование платформы**:
  - `GET /api/admin/dashboard` — статистика всей платформы, пользователи, курсы, категории, блог.
  - `POST /api/admin/users/:id/toggle-block` — блокировка/разблокировка пользователя.
  - `POST /api/admin/users/:id/role` — изменение роли пользователя.
  - `POST /api/admin/categories` — добавление категории.
  - `DELETE /api/admin/categories/:id` — удаление категории.
  - `POST /api/admin/blog` — публикация статьи.
  - `DELETE /api/admin/blog/:id` — удаление статьи.
- **Преподаватели и блог**:
  - `GET /api/teachers` — список преподавателей со средним рейтингом и их курсами.
  - `GET /api/blog` — список публикаций с фильтрацией и поиском.
  - `GET /api/blog/:id` — просмотр статьи и списка комментариев.
  - `POST /api/blog/:id/comments` — отправка комментария к статье.

## 🔒 Безопасность и валидация
- Все входные данные форм валидируются на клиенте и сервере.
- Пароли проверяются на минимальную длину и совпадение подтверждения.
- Проверка прав доступа: защищенные разделы преподавателя и администратора доступны только авторизованным пользователям с соответствующими ролями.
- При блокировке пользователя администратором доступ к входу немедленно блокируется.
