Описание курса

Этот курс научит вас программировать на JavaScript с нуля. Вы освоите синтаксис, работу с DOM, асинхронность, современные инструменты и соберёте 5 реальных проектов.

Чему вы научитесь

  • Писать чистый и современный JavaScript (ES6+).
  • Работать с DOM и событиями.
  • Использовать fetch и async/await.
  • Собирать проекты с помощью сборщиков.

Для кого курс

Для начинающих разработчиков, верстальщиков и всех, кто хочет освоить веб-программирование.
